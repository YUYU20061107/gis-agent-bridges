# Skill: mapgis-bridge（MapGIS 桥接，探针先行）

让 AI Agent 接入 MapGIS（中地数码）工程的桥接包。本 Skill 与系列里其他桥
最大的不同：**MapGIS 的 Python API 形态未经证实，第一阶段只做探针**。
在探针给出肯定结论之前，任何"MapGIS 可以这样操作"的说法都不许当真，
更不许据此写业务代码。

## 为什么探针先行

- 厂商官方口径称 MapGIS Objects SDK 提供 C++/Java/Python 开发资源，但
  Python 绑定的模块名、安装位置、入口清单没有公开权威文档。
- MapGIS Desktop 是否存在"当前会话"接口（能附着到 GUI 里正打开的工程）
  未经证实，实时桥路线未定。
- 因此本 Skill 的工作流是：**先跑探针 → 完整回传 JSON → 等维护者决策路线**。

## 第一步（永远的第一步）：运行探针

```
<python> scripts/probe_mapgis.py
```

- 首选解释器：MapGIS 自带的 Python 解释器（若有）；其次系统 Python 3。
  两个解释器都可用时，**各跑一遍，两份 JSON 都回传并注明解释器**。
- 输出是单行 JSON，必须**原样、完整**附在回报里，删减视为未执行。
- 退出码 0 = 找到候选绑定；退出码 1 且含 `MAPGIS_PYTHON_NOT_FOUND`
  = 本机未证实存在可用绑定。**这不是失败，是第一阶段的合法结论**，
  回报后停下等维护者决策，不许自行进入下一步。

## 探针命中后才可做的动作（v0.1，仅此三项）

所有动作通过桥接脚本执行，脚本输出单行 JSON，必须原样附在回报里。

### 1) preflight —— 环境预检（只读）
```
<python> scripts/mapgis_bridge.py preflight
```
即探针的复跑与结论确认；不通过不许进入任何业务动作。

### 2) backup —— 备份工程文件（只读原件）
```
<python> scripts/mapgis_bridge.py backup <工程文件.MPJ 路径>
```
在同目录生成 `<原名>.bak-<yyyymmdd-HHMMSS>` 副本（含同名数据文件），
回报每份副本的 sha256。**任何后续动作之前必须先 backup。**

### 3) inspect —— 工程盘点试探（只读，骨架）
```
<python> scripts/mapgis_bridge.py inspect <工程文件.MPJ 路径>
```
脚本按候选 API 多策略尝试打开工程。两种合法结果：
- 命中某个入口：回报 `opened_via` 与返回对象的公开成员面（v0.1 只到成员面，
  不解读语义，不声称已完成数据盘点）；
- 全部失败：`NOT_SUPPORTED` 加尝试清单——**如实回报，不许编造图层/数据清单**。

## 安全纪律（硬规则，违反即停）

1. **探针边界**：探针结论之外一律未知。不许猜模块名、不许虚构类与方法、
   不许把其他 GIS 软件的 API 套到 MapGIS 头上。
2. **不装包**：探针未命中时，不许 pip install 任何"看起来像"的包，
   不许改注册表/环境变量去"凑"一个环境出来；记录现象、回报、停下。
3. **原件只读**：禁止对用户指定的原始工程执行任何 save / 写入 / 删除动作。
4. **不碰无关环境**：不要使用或修改与本任务无关的既有项目环境
   （解释器环境、依赖与配置）。
5. **许可错误即停**：出现许可类报错，回报原始报错全文，不许反复试探，
   更不许尝试任何绕过许可的做法。
6. **路径含中文/空格**一律用引号包裹并按原始字符串传参；JSON 输出保持
   UTF-8 不转义。
7. 每一步的脚本原始输出（JSON）都要留档回传；失败也要回传，不许只报结论。

## 常见结果对照

| 现象 | 含义 | 处置 |
|---|---|---|
| `MAPGIS_PYTHON_NOT_FOUND` | 全部候选模块导入失败，本机未证实有可用绑定 | 回传完整 JSON，停，等维护者决策路线 |
| `install_dirs_found` 非空但模块全失败 | 装了 MapGIS 桌面，但 Python 绑定不在当前解释器的路径上 | 如实回报；若 MapGIS 自带解释器，换它再跑一遍探针 |
| 探针命中模块但顶层符号与 GIS 无关 | 可能撞名其他同名包 | 看 `found.file` 路径判断，如实回报，不许将就使用 |
| inspect 返回 `NOT_SUPPORTED` | 命中模块的工程打开入口与脚本假设不符 | 回传探针 + 尝试清单，等维护者据实收紧，不许临时发明新策略当定案 |
| 许可类报错 | MapGIS 许可不可用 | 停，回报原文 |

## 回报格式

每次动作后回报：①一句话结论；②脚本 JSON 原文；③若动过文件，列出新建
文件路径清单。探针阶段额外注明：执行机器、解释器路径与版本、MapGIS
桌面版本（界面可见时）。没有 JSON 的回报视为未执行。
